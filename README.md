# Shiawase Extensions

Repo sumber ekstensi manga Shiawase untuk Mihon/Tachiyomi.

## Ekstensi

- Ryukomik (`src/id/ryukomik`) - sumber manga berbahasa Indonesia.

## Penggunaan

Tambahkan repo ini ke Mihon/Tachiyomi dengan menyalin URL berikut:

https://github.com/fluxxex90etc/shiawase-manga-repo/raw/repo/index.pb
